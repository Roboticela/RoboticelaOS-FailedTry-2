# Roboticela color palette

Product UI tokens. Resolve through the token, never mix light-mode and dark-mode hex in one view. `--brand-primary` is the only interactive accent. `--accent-teal` is success/verified only.

## Brand / primary

| Token | Light | Dark | Use |
|---|---|---|---|
| `--brand-primary` | `#0E7AFF` | `#3B9EFF` | Buttons, active nav, links |
| `--brand-primary-hover` | `#0A6AE8` | `#5CADFF` | Hover |
| `--brand-primary-active` | `#0757C7` | `#2E8CE6` | Pressed |
| `--brand-primary-disabled` | `#B8D9FF` | `#1E3A5C` | Disabled primary |
| `--brand-primary-subtle` | `rgba(14,122,255,0.10)` | `rgba(59,158,255,0.15)` | Selected / badge |
| `--brand-primary-focus-ring` | `rgba(14,122,255,0.25)` | `rgba(59,158,255,0.30)` | Focus rings |

## Accent (teal, sparing)
