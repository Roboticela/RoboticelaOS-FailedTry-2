# RoboticelaOS desktop UI

Author the shell window's document in Vite + React. `Scripts/Build/BuildDesktopUi.ps1` compiles it to plain HTML, CSS and JS (`Build/Desktop/Ui/`) and writes `Runtime/Source/RoboDesktop/Generated/DesktopPage.h` for the OS scene.
