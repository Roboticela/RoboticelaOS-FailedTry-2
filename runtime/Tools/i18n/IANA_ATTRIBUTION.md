# IANA Language Subtag Registry attribution

RoboI18N canonicalization tables are derived from the
**IANA Language Subtag Registry** (BCP 47).

- URL: https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry
- File-Date pin: see `robo_i18n_version.py` / `RoboI18NVersion.h`
- Checksum: `manifest.json`

The registry is maintained by IANA. Redistribution of derived tables should
preserve provenance documentation. This is **not** the Unicode Data Files
